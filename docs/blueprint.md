# **App Name**: Kofi Oracle

## Core Features:

- QR Code Scan Entry: Upon scanning a QR code, the user is immediately directed to the full-screen phrase revelation experience.
- Dynamic Phrase Revelation: Displays a single, randomized phrase with subtle fade-in animation, centered vertically and horizontally, prioritizing extreme minimalism.
- Phrase Database Randomization: A system that serves one unpredictable phrase from a curated list, ensuring users never know what to expect next or how many phrases exist.
- Essential Action Buttons: Provides options to 'Save', 'Share', or 'Scan again later' below the revealed phrase, devoid of clutter or additional navigation.
- Editorial Landing Page: A mysterious homepage with brutal minimalism, oversized typography (Nwa. Bua. Boeletsa.), and art poster-like isolated phrases with hidden meanings and tiny translations.
- Optional Usage Limitation: Implements an optional mechanism to limit how often a user can reveal a new phrase, such as once per cup or once per day, fostering emotional tension.

## Style Guidelines:

- Light Mode Background: A clean, desaturated 'Paper White' for the landing page, expressed as hex #F4F4F4. Dark Mode Background: A deep, quiet 'Obsidian' for the phrase revelation experience, expressed as hex #0A0A0A.
- Primary Typography Color: A refined, almost black hue for dominant text, ensuring strong contrast on light backgrounds and a subtle presence on dark ones, expressed as hex #121212.
- Accent Color: A deep, rich 'Oxblood Red' used sparingly for minimal details and highlights, creating moments of quiet intensity, expressed as hex #BC0000.
- Primary typography for headlines and bold statements: 'Inter Tight' (sans-serif), chosen for its bold, cinematic, and poster-like character. Secondary typography for subtle translations and editorial text: 'Newsreader' (serif), providing an elegant, slightly formal contrast.
- Brutal Minimalism with Huge Whitespace: Prioritizing vast amounts of negative space around content to create a gallery-like, premium feel. Layouts are clean, responsive, and mobile-first, often featuring asymmetrical arrangements.
- Restrained Motion: Incorporates subtle, deliberate animations like slow fade-ins for text, gentle background grain effects, and 'receipt-printer style' reveals, powered by Framer Motion, avoiding any noisy or flashy transitions.
